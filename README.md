# 스타 레인저 우주 실험실 (연성중 3학년 과학 · 별과 우주)

모둠이 측정값을 보내면 칠판 그래프에 실시간으로 모이는 실험 데이터판.

- 학생(모둠 대표): `index.html` — 학년·반·모둠·입력자 → 측정표 → 📡 칠판으로 보내기
- 교사(칠판): `board.html` — 교사 PIN → 실험 시작/마감 → 반 그래프, 💡 규칙 공개, CSV, 기준 은하 바꾸기 애니메이션

| 실험 | 성취기준 | 칠판에서 발견하는 것 |
|---|---|---|
| 📏 시차 측정 (연필·엄지) | [9과23-01] | 거리 2배 → 움직임 1/2 (반비례), 1/거리 그래프는 직선 |
| 🎈 풍선 우주 팽창 | [9과23-03] | 처음 거리 ∝ 늘어난 거리 (허블 법칙), 어느 은하에서 봐도 같음 → 중심 없음 |

저장: 연성중 「한눈 체크」 Apps Script (시트 '실험'). 이 저장소에는 키·PIN이 없습니다.
